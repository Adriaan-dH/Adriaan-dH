## Featured Projects

### Tournament Engine for Competition-Style Tutorials

**Go, gRPC, gRPC-Web, Protocol Buffers, PostgreSQL, Kubernetes, Docker, Minikube, Next.js, TypeScript, React Query**

Built a full-stack platform for running university Othello bot tournaments and tutorial-style programming evaluations on server infrastructure. Implemented GitLab submission discovery, containerised workload execution, standings, logs, diagnostics, timing, and live page updates.

### Layita Foundation WhatsApp Chatbot and Monitoring Dashboard

**Python, Flask, SQLite, React, Vite, Google Gemini API, RAG**

Built a prototype for a South African NGO to support caregivers through a WhatsApp Business chatbot and staff-facing monitoring dashboard. Supported curated content, isiXhosa-oriented workflows, human review and escalation, engagement tracking, FAQ generation, chat visibility, and analytics.

### Industry SME Agent for Affiliate Marketing

**Python, Flask, React, Vite, DuckDB, Neo4j, Google Gemini API, SQL, Cypher**

Built an end-to-end system where users can ask natural-language questions about affiliate-marketing data and receive data-driven answers with tables, charts, and chatbot-style responses. Implemented SQL/Cypher generation, local querying, and knowledge graph construction from CSV data.

### Multiplayer Trivia Web Application

**React, Node.js, Express.js, PostgreSQL, WebSockets, JWT, bcrypt**

Developed a real-time multiplayer quiz platform with authentication, admin controls, live matches, scoring, match history, profile management, and synchronised gameplay state.
